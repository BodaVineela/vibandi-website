# Vibandi LLC website

A one-page static site. Everything (HTML, CSS, script) is in `index.html`, so it can be hosted anywhere that serves plain files (GitHub Pages, Netlify, Cloudflare Pages).

## Editing
Search `index.html` for `EDIT:` comments. Each one sits above text you should replace:
- Headline and intro
- The three division cards (Technology, Media, Future ventures)
- About text and principles
- Contact email (currently the placeholder `hello@vibandi.com`) and location

## Adding a division
Copy one `<article class="division">` block in the Divisions section and change its name, status and description. Also add a matching `<div class="node">` in the family tree near the top if you want it shown there.
